Media source

Host chooses the source. Each participant controls playback independently. R2 or a direct HTTPS URL plays without Drive processing.

Uploads use the Worker endpoint in media-config.js. For V2, uploads up to 90 MiB are supported in one request; larger files require the optional Wrangler CLI upload described in README. Never place the upload password in GitHub or share it with guests.

A local file path or localhost URL will not work for friends. A PC source requires a secure publicly reachable HTTPS tunnel with range requests and correct CORS.

Subtitles

Host uploads SRT/VTT to R2 and shares it with the room, or paste an HTTPS VTT URL. Subtitles apply to direct video, not the Google Drive iframe.
