Media source

Host chooses the source. The host controls synchronized playback for R2 and direct HTTPS media. Google Drive preview playback remains manual.

Uploads use the Worker endpoint in media-config.js. Files up to 5 GiB use multipart uploads automatically. Keep this tab open until uploading and finalization finish. Never place the upload password in GitHub or share it with guests.

Expiration is measured from upload initialization. Cloudflare checks hourly, so deletion may happen later than the selected time. Do not choose a period shorter than your planned movie night.

A local file path or localhost URL will not work for friends. A PC source requires a secure publicly reachable HTTPS tunnel with range requests and correct CORS.

Subtitles

Host uploads SRT/VTT to R2 and shares it with the room, or paste an HTTPS VTT URL. Subtitles apply to direct video, not the Google Drive iframe.
